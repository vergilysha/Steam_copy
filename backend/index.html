Steam Game API

Search Steam for game info and find torrent magnet links — all running in your browser via a Service Worker. Zero backend, zero infrastructure.

POST ./api.html

⚙️ How it works

A Service Worker (api-sw.js) intercepts every POST request made to api.html and returns a JSON response before it even hits the network. Direct browser visits (GET) are immediately redirected here.

ℹ The SW installs automatically when you open this page. After activation, all POST requests to api.html are handled locally — no round-trips, no server.

Usage from JavaScript

const res = await fetch('./api.html', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ action: 'search', query: 'cyberpunk' }) }); const data = await res.json();

🔍 Search Game

Finds the single best-matching game on Steam by name. Supports partial and fuzzy queries. Returns price, discount, description, images, and metadata.

POST ./api.html Search Steam catalogue

Request body (JSON)

FieldTypeReqDescription
action string ✓ Must be "search"
query string ✓ Game name — partial or fuzzy

Request example

{ "action": "search", "query": "cyberpunk 2077" }

Response fields

FieldTypeDescription
idnumberSteam App ID
namestringOfficial game name
imagestringHeader image URL
screenshotsstring[]Up to 3 thumbnail URLs
descriptionstringShort description
pricestringOriginal price (e.g. $59.99)
current_pricestringPrice after discount
discountnumberDiscount % (0 if none)
sale_pricestring|nullSale price or null
genresstring[]Genre list
developersstring[]Developer(s)
metacriticnumber|nullMetacritic score
release_datestring|nullRelease date string
store_urlstringSteam store page URL

Response example (200)

{ "id": 1091500, "name": "Cyberpunk 2077", "image": "https://cdn.akamai.steamstatic.com/steam/apps/1091500/header.jpg", "screenshots": ["https://..."], "description": "An open-world, action-adventure RPG...", "price": "$59.99", "current_price": "$29.99", "discount": 50, "sale_price": "$29.99", "genres": ["RPG", "Action"], "developers": ["CD PROJEKT RED"], "metacritic": 86, "release_date": "Dec 10, 2020", "store_url": "https://store.steampowered.com/app/1091500" }

⬇️ Download Links

Searches across all local repack databases and returns every matching entry with its magnet links. Results are sorted by fuzzy-match score.

POST ./api.html Find torrent magnets

Request body (JSON)

FieldTypeReqDescription
action string ✓ Must be "download"
query string ✓ Game name to search for (partial match OK)

Sources

🔵 FitGirl Repacks 🔴 DODI 🟠 Xatab 🟢 OnlineFix

Request example

{ "action": "download", "query": "elden ring" }

Response fields

FieldTypeDescription
querystringYour original query
totalnumberNumber of matches found
resultsobject[]Matched entries (up to 20)
results[].sourcestringRepack source name
results[].titlestringFull repack title
results[].fileSizestringDownload size
results[].uploadDatestringISO 8601 upload date
results[].magnetsstring[]Magnet URIs

Response example (200)

{ "query": "elden ring", "total": 3, "results": [ { "source": "FitGirl", "title": "Elden Ring v1.12.3 + All DLC [FitGirl Repack]", "fileSize": "34.2 GB", "uploadDate": "2024-06-01T00:00:00.000Z", "magnets": ["magnet:?xt=urn:btih:..."] } ] }
